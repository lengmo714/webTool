UTF-8 Byte Counter

Measure the encoded size of text, including emoji and non-Latin characters, and check it against your byte budget.

How to measure text size in bytes

  1. Paste or type your text.
  2. Optionally enter a whole-number byte limit.
  3. Read the size report or copy it for a technical handoff.

Why bytes and characters differ

UTF-8 uses one to four bytes per Unicode code point. The letter A takes one byte, é takes two, and many emoji take four. A visible symbol can contain several code points, so code-point counts are not counts of visible characters.

What is included?

The report measures the text in this textarea using UTF-8 without a byte-order mark. Browser textareas normalize line endings to LF; a downloaded file using CRLF may be larger. UTF-16 units correspond to JavaScript string length. KiB means 1,024 bytes. This is useful for plain-text field limits, but JSON escaping, request headers, and compression can change a transmitted payload's size.

Does my input leave the browser?

The tool processes your input locally with JavaScript. No account or upload is needed.
