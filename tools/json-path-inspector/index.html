JSON Path Inspector

Inspect JSON leaf values and their exact JSON Pointer paths, including array indexes and escaped object keys, directly in your browser.

How to inspect JSON paths

  1. Paste valid JSON or load the sample.
  2. Read one JSON record per leaf, with pointer, type, and value fields.
  3. Copy the newline-delimited records into your debugging notes.

JSON Pointer syntax

The name of this tool refers to inspecting paths, not executing JSONPath queries. It outputs JSON Pointer strings: /user/name selects the name key inside user, and /user/roles/0 selects the first role. A tilde in a key becomes ~0 and a slash becomes ~1, so the key a/b is represented by /a~1b.

Root values and empty containers

The empty pointer string selects the document root. Empty objects and arrays are included as leaves so they are not lost. Null, booleans, strings, and numbers are labeled by type. Output uses one compact JSON object per line, keeping embedded newlines in values escaped.

Limits and number precision

Input is limited to 200,000 characters and 10,000 visited values. Standard browser JSON parsing applies: duplicate keys keep their final value, and very large numbers may lose precision. Non-finite numbers are rejected; represent exact large identifiers as strings. Parsing happens locally without uploading your JSON.
