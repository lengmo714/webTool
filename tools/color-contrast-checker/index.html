    What does a color contrast checker measure?

    This tool calculates the contrast ratio between a text color and its background using WCAG relative luminance. The result helps you estimate whether a color pair is readable enough for standard-size text, large text, buttons, labels, and interface copy.

    How to check contrast for accessibility

    1. Enter the foreground and background HEX colors you want to compare.
    2. Optional: replace the preview sentence with your own sample text.
    3. Run the checker to see the ratio plus AA and AAA pass or fail guidance.

    When this tool helps

    • Review landing pages, dashboards, and design systems for readable text combinations.
    • Compare brand colors before shipping new buttons, alerts, or banners.
    • Quickly test light-on-dark and dark-on-light pairs without opening design software.
