    What does URL encoding do?

    URL encoding turns characters that have special meaning in a web address, such as spaces, ampersands, and non-English characters, into safe percent-encoded values. This keeps a value intact when it is placed inside a query parameter or another URL component.

    How to encode or decode a URL component

    1. Paste the plain text or percent-encoded string into the input field.
    2. Choose Encode for URL to make a safe component, or Decode URL text to read it.
    3. Review the output and copy it when it looks right.

    Useful cases for URL encoding

    • Prepare search queries, labels, or notes for use in URL parameters.
    • Read encoded links from analytics reports, APIs, or browser logs.
    • Safely include Unicode characters and punctuation in a URL value.
