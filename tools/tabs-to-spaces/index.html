Tabs to Spaces Converter

Expand tabs to spaces using column-aligned tab stops. Choose a tab width and convert indentation or every tab locally.

How to expand tabs

  1. Paste text containing real tab characters.
  2. Choose a tab width from 1 to 16 columns.
  3. Convert every tab or just leading indentation, then copy the result.

Tab stops are column aligned

With a width of four, a tab after one character inserts three spaces; a tab at column zero inserts four. Each line starts at column zero. Existing spaces remain unchanged. Leading indentation mode stops converting after the first character that is neither a space nor a tab.

Unicode and line endings

Each Unicode code point counts as one column. This is a text convention, not a terminal display-width calculation: emoji, combining marks, and wide characters may look different in an editor. Windows CRLF and older Mac CR line endings become LF. Trailing newlines are retained. Input is limited to 100,000 characters; output to 1,600,000 characters.

Where is my input processed?

All conversion runs locally in your browser. Your input is not submitted for processing.
