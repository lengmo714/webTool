Four-Band Resistor Color Code Calculator

Decode four resistor color bands into resistance in ohms, tolerance, and minimum and maximum values directly in your browser.

Read four resistor bands

Select the two digit bands, then the multiplier and tolerance. Brown, black, red, gold represents 1,000 ohms with 5% tolerance: 950 to 1,050 ohms.

Calculation and color reference

Resistance is (10 × first digit + second digit) × multiplier. The tolerance determines the range around that nominal value. Digit colors run from black (0) through brown, red, orange, yellow, green, blue, violet, gray, and white (9). Gold and silver multipliers allow fractional ohm values.

Scope

This decoder handles four-band resistors only. It does not decode five-band, six-band, or surface-mount markings, or determine power ratings. All calculations run locally.

Color mappings follow the Vishay color-code reference.
