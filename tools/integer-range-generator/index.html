Integer Range Generator

Generate an ascending or descending integer sequence with an exact start, end, and step, then copy it as lines, CSV, or a JSON array.

Advertisement

How to generate a number sequence

Enter integer start and end bounds and a nonzero signed step. Use a positive step to count upward or a negative step to count downward. Choose an output format and copy the result.

Inclusive bounds and steps

The start is always included. The end is included only if the sequence reaches it exactly. For start 1, end 8, and step 3, the result is 1, 4, 7. Equal bounds produce one value for any nonzero step. A step pointing away from the end is rejected.

Exact large integers

Calculations use BigInt, preserving integers beyond JavaScript’s safe number range. Each field accepts up to 100 digits, excluding its optional sign. Output is limited to 10,000 values. JSON output uses strings to preserve exact large integers when imported into other applications. Decimal values and scientific notation are not accepted.
