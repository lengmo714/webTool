What is a URL slug?

A URL slug is the readable last part of a web address. Clear, lowercase, hyphenated slugs make links easier to share and understand.

How to use this tool

  1. Type or paste a title.
  2. Copy the slug generated as you type.
  3. Use it as the URL path in your CMS.
