URL Query String Inspector

Inspect decoded URL query parameters as ordered JSON pairs, preserving duplicate keys, blank values, and Unicode locally in your browser.

Advertisement

How to inspect query parameters

  1. Paste an absolute HTTP or HTTPS URL, a query beginning with ?, or raw key=value pairs.
  2. Review the decoded JSON array in its original order.
  3. Copy the result for debugging or documentation.

Duplicate keys are preserved

A query such as tag=red&tag=blue returns two separate entries. Empty values and empty keys are retained, while empty separators are skipped. Results are an array of key/value pairs, so repeated names never overwrite each other.

Decoding rules

Percent escapes are decoded as UTF-8 and a plus sign means a space. Use %2B for a literal plus and %23 for a literal hash. A literal hash begins a fragment and is excluded. Malformed percent escapes or invalid UTF-8 produce an error. Relative URLs are not supported; paste only their query portion. A bare name is accepted as a key with an empty value.

Does this upload my input?

Conversion happens locally in your browser with JavaScript. No account or upload is required.
