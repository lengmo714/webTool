JSON Merge Patch Tool

Apply a JSON merge patch to a target document: merge object members, remove keys with null, and replace arrays locally in your browser.

Advertisement

Apply a merge patch

Paste a target JSON document and a patch. Object members are merged recursively. A null member in the patch removes that key, while arrays and scalar values replace the corresponding target value. The sample changes a title, replaces tags, and removes an email.

Replacement and deletion rules

An object patch applied to a non-object starts with an empty object. A non-object patch replaces the entire target, so a top-level null produces null. Arrays are replaced as a whole; this is not an operation-list JSON Patch editor. A null object member requests deletion and cannot be used to assign a literal null member.

Input limits and privacy

Both inputs must be valid JSON, up to 100,000 characters each and 100 levels deep. Numbers use standard JavaScript precision; quote identifiers and integers that exceed its safe integer range. Duplicate keys follow JSON parsing rules: the last value wins. Document processing happens in your browser.
