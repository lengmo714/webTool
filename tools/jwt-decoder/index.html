    What this JWT decoder shows

    This tool decodes the Base64URL-encoded header and payload segments from a JSON Web Token directly in your browser. It helps you inspect claims and metadata without sending tokens to a server.

    How to decode a JWT

    1. Paste the token into the JWT field.
    2. Select Decode JWT to pretty-print the header and payload.
    3. Review the standard claims, then copy either JSON block if you need it elsewhere.

    Important limitation

    Decoding a JWT is not the same as verifying it. This page does not confirm the signature, issuer, audience, or trustworthiness of the token. Use it for inspection and debugging only.
