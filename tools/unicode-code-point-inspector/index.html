Unicode Code Point Inspector

Inspect pasted characters as Unicode code points, JSON escapes, and UTF-8 bytes without sending text anywhere.

Advertisement

See what a character contains

Paste text to get one row per Unicode code point. The report includes its U+ notation, a JSON-safe representation, and a readable label for spaces, tabs, and line breaks.

Why code points matter

Some visible characters use more than one JavaScript UTF-16 unit, while UTF-8 storage may take one to four bytes for each code point. This view makes unusual punctuation, emoji, and invisible whitespace easier to identify.

Private inspection with a practical limit

All processing runs locally. The tool reports up to 1,000 rows and accepts up to 50,000 UTF-16 units, which keeps a detailed report responsive for ordinary pasted text.
