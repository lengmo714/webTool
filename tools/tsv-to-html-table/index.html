TSV to HTML Table Generator

Convert pasted spreadsheet cells into an escaped HTML table with an optional header row and caption, directly in your browser.

Advertisement

How to convert spreadsheet cells

Copy a spreadsheet range, paste the tab-separated text, choose whether the first row is a header, and optionally add a caption. Copy the generated HTML into your page source.

Safe, semantic table markup

Cell text and captions are HTML-escaped, so angle brackets and ampersands remain text. Header cells use scope="col". The result includes a table, optional caption and header, and a table body; styling is left to your website.

Input format and limits

This tool reads literal tabs as cell separators and line breaks as rows. It does not interpret quoted multiline spreadsheet cells or CSV quoting. One final line break is ignored; other blank rows are preserved. Short rows are padded with empty cells. Limits are 200,000 characters, 1,000 rows, 100 columns, and 20,000 output cells.

Private browser processing

Your input is processed locally in this browser tab without uploading it to a server.
