Integer Bit Length Calculator

Find the exact binary width and signed or unsigned byte requirements of a decimal integer, including very large values.

Measure a number's binary width

Enter a base-10 integer to see its binary magnitude, the number of bits it needs, and the smallest whole-byte unsigned representation. This is useful when preparing binary formats or checking field limits.

Signed values use a sign bit

Signed byte results use the minimum two's-complement width. Positive values need room for a leading zero sign bit, while negative values are sized from the representable range ending at minus one.

Exact large-integer calculations

The calculator uses JavaScript BigInt rather than floating-point numbers, so integer precision is retained for up to 100,000 decimal digits. Input stays in your browser; decimal points and scientific notation are rejected.
