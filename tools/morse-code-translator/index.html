Morse Code Translator

Translate English letters and digits to Morse code or decode dots and dashes into text, with clear word separators and local processing.

Advertisement

How to translate Morse code

Choose a direction and paste text or Morse code. In Morse input, separate letters with spaces and words with a slash. For example, ... --- ... / .---- decodes to SOS 1. Copy the result for a worksheet or message.

Supported alphabet and spacing

This translator supports the 26 English letters and digits 0–9. Lowercase letters become uppercase. Text whitespace becomes a single word boundary; leading and trailing whitespace is removed. Punctuation and non-English letters are rejected so unsupported characters are never silently lost. Morse input uses ASCII dots and hyphens, not typographic dashes.

Limits and interpretation

Input is limited to 50,000 characters. This is a written notation translator; it does not generate audio or interpret signal timing. Morse output places one space between letters and a spaced slash between words.
