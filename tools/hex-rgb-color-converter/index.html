    Convert between HEX, RGB, and HSL

    HEX and RGB are common ways to describe the same screen color. This converter accepts a six-digit HEX code or red, green, and blue values, then calculates matching CSS-ready values including HSL.

    How to use this color converter

    1. Paste a six-digit HEX code, or enter the red, green, and blue channels.
    2. Choose the matching conversion button.
    3. Copy the result you need for a stylesheet, design token, or project note.

    When color conversion is useful

    • Translate a brand HEX value into RGB for an interface or image workflow.
    • Adjust lightness and saturation with HSL while retaining the same base color.
    • Check and share CSS color codes with teammates.
