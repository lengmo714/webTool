Fixed-Width Bitwise Calculator

Calculate unsigned AND, OR, XOR, NOT, and logical shifts at 8, 16, 32, or 64 bits, with exact decimal, binary, and hexadecimal results.

Advertisement

Compare bits and shift values

Enter unsigned integers in decimal, hexadecimal with 0x, or binary with 0b. AND keeps bits set in both operands, OR keeps bits set in either, and XOR keeps bits set in exactly one. NOT flips each bit of A within the chosen width.

Fixed-width rules

Operands must fit the selected width; an 8-bit operand ranges from 0 to 255. Left shifts discard bits beyond the width. Right shifts fill with zeros. Shifting by the full width produces zero. Both shifts operate on A; B is used only for AND, OR, and XOR.

Exact large integers

BigInt arithmetic preserves all 64 bits. Results show unsigned decimal, zero-padded hexadecimal, and zero-padded binary. Negative values, fractions, and shifts outside zero through the selected width are rejected. Input stays in this browser tab.
