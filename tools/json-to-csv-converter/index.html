How to convert JSON to CSV

  1. Paste a JSON array containing objects.
  2. Choose whether to protect formula-like text.
  3. Copy the CSV into a file with a .csv extension.

How columns and values are handled

Headers include all keys in first-seen order. Missing fields and null become empty cells. Nested objects and arrays become JSON strings. Commas, quotes, and line breaks are escaped with CSV double quotes. Output uses CRLF record separators. Empty arrays produce no output.

Spreadsheet formula protection

Enabled by default, protection adds an apostrophe to text cells and headers that begin with =, +, -, or @ after whitespace. This changes the exported text and helps prevent spreadsheet formula interpretation. Disable it when exact text is required for a trusted non-spreadsheet import. Spreadsheet import behavior varies; inspect imported cells before using them.

Does my input leave the browser?

Your input is processed locally with JavaScript. No upload or account is needed.
