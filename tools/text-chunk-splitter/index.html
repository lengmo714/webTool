Text Chunk Splitter

Split text into fixed-size Unicode code point chunks and copy a JSON array that preserves every space and line break for easy reconstruction.

Advertisement

How to split text into chunks

Paste text and choose a chunk size from 1 to 10,000 code points. Copy the resulting JSON array into your script or workflow. The final chunk may be shorter. Empty input produces an empty array.

Lossless text segments

Every space, tab, and line break is retained in the input value. JSON escapes line breaks and quotes so each chunk stays unambiguous. After parsing the array, joining its strings with an empty separator reconstructs the input. Browser textareas may normalize pasted CRLF line endings to LF.

Unicode and size limits

Chunks count Unicode code points, not UTF-8 bytes or visible grapheme clusters. A single emoji code point stays intact, but combining accents and multi-code-point emoji sequences can cross a boundary. Words can also be split. Input is limited to 100,000 UTF-16 units and output to 10,000 chunks.
