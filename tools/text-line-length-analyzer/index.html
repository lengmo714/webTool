Text Line Length Analyzer

Measure every text line by Unicode code points, UTF-16 units, and UTF-8 bytes with a compact local report.

Measure lines without guessing

Paste a title list, source excerpt, or text field content to see a row for each line. The summary identifies the shortest and longest lines and the line that takes the most UTF-8 bytes.

Characters, code points, and bytes

JavaScript UTF-16 units are what its string length reports. Code points keep an emoji intact, while UTF-8 bytes estimate encoded plain-text size. A visible grapheme can still contain several code points, such as an accented character built with a combining mark.

Line endings and limits

Windows and old Mac line endings are normalized to LF before analysis. Blank lines are counted. Input is limited to 200,000 UTF-16 units and never leaves your browser.
