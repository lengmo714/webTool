    What does a number base converter do?

    This tool interprets an integer in one radix, converts it to decimal internally, and then rewrites it in the base you choose. It is useful for binary flags, octal permissions, hexadecimal values, encoded IDs, and other developer-facing formats.

    How to convert between number bases

    1. Paste the integer you want to convert.
    2. Select the base the input currently uses and the base you want as output.
    3. Run the conversion and copy the target-base result or the decimal, binary, octal, and hex views.

    When this tool helps

    • Inspect binary feature flags, masks, and bit patterns.
    • Translate hexadecimal values for CSS colors, debug logs, or system output.
    • Quickly move between decimal IDs and compact base-36 or base-16 representations.
