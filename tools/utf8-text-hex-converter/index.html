How to convert text and hex bytes

  1. Select text to hex or hex to text.
  2. Paste Unicode text or hexadecimal byte pairs.
  3. Copy the converted result.

UTF-8 bytes versus characters

ASCII letters use one byte each. Accented letters and emoji often use multiple bytes. For example, A becomes 41 and an emoji can occupy four byte pairs. Output uses uppercase hex separated by spaces.

Accepted hex input

Paste continuous hex or byte pairs separated by whitespace. Spaces, tabs and newlines are ignored. Odd digit counts, 0x prefixes, punctuation and invalid UTF-8 sequences are rejected. A UTF-8 byte order mark is preserved as a character. This tool decodes text, not arbitrary binary files.

Does this upload my input?

Conversion happens locally in your browser with JavaScript. No account or upload is required.
