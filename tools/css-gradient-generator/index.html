How to use this CSS gradient generator

  1. Choose a starting and ending color.
  2. Set the angle that matches the direction you want.
  3. Copy the generated background declaration into your stylesheet.

What is a linear gradient?

A linear gradient blends colors along a straight line. It is useful for page backgrounds, buttons, hero sections, cards, and other visual accents without needing an image file.

Does this generator upload my colors?

No. The preview and CSS code are generated entirely inside your browser tab.
