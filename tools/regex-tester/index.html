Regular Expression Tester

Test a JavaScript regex against your own sample text and inspect every match without sending either to a server.

Enter a pattern and test it against the sample text.

How to test a regular expression

  1. Enter the pattern without the surrounding slash characters.
  2. Add JavaScript flags such as g for all matches or i for case-insensitive matching.
  3. Paste test text and select Test pattern to view the results.

What does this regex tester support?

This tool uses the JavaScript regular-expression engine built into your browser. It reports every match, including its position, and clearly displays invalid patterns or flags.

Keep test data private

Patterns and text are evaluated locally in your browser. They are not uploaded or saved by this tool.
