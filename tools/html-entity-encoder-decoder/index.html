    What are HTML entities?

    HTML entities are character codes used to display reserved characters safely in HTML. For example, an ampersand can be written as &amp; and a less-than sign as &lt;. They are helpful when text should appear literally instead of being interpreted as markup.

    How to use this HTML entity converter

    1. Paste text that you want to escape, or paste entity-encoded text that you want to read.
    2. Select Encode HTML text or Decode entities.
    3. Copy the result for your document, code sample, or content editor.

    Common uses

    • Escape snippets before showing them as literal HTML examples.
    • Decode copied content containing named or numeric entities.
    • Prepare text for HTML-based templates and documentation.
