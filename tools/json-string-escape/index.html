JSON String Escape & Unescape

Convert plain text to a JSON string literal, or decode a quoted JSON string back to readable text.

How to escape or unescape a JSON string

  1. Choose the conversion direction.
  2. Paste plain text to escape, or a complete double-quoted JSON string to unescape.
  3. Copy the result into your editor.

Quotes, backslashes, and line breaks

Escape mode uses JSON string syntax and includes surrounding double quotes. Quotes and backslashes are escaped; a line break becomes the literal sequence \n. Unicode text remains readable wherever JSON permits it. Unescape mode interprets valid JSON escapes, including \uXXXX sequences.

One string at a time

This tool handles a single string value. It rejects objects, arrays, numbers, and malformed escapes. Empty text escapes to "". For a full JSON document, use the JSON Formatter & Validator. JSON escaping is not HTML escaping and does not make text safe to embed directly in an HTML script element.

Does my input leave the browser?

The conversion runs locally with JavaScript. No upload or account is needed.
